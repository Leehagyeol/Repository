# "저장소에 담기" 단축어 만들기 (F13)

YouTube·Safari·인스타그램 등에서 **공유 버튼 → 저장소에 담기**를 누르면 저장소 앱의 추가 화면이 링크가 채워진 채로 열리게 합니다.

아이폰은 웹앱이 공유 목록에 직접 나타나는 것을 막아 두어서, 단축어 앱을 거쳐 보냅니다.

## 만들기 (한 번만)

1. **단축어** 앱을 열고 오른쪽 위 **+** 를 누릅니다.
2. 맨 위 이름을 **저장소에 담기** 로 바꿉니다.
3. 아래쪽 **ⓘ(세부사항)** → **공유 시트에 보기**를 켜고 **완료**.
   - 맨 위에 "공유 시트에서 … 입력 받기" 블록이 생깁니다. 파란 글자(받는 종류)를 눌러 **URL**, **텍스트**, **Safari 웹 페이지**만 남기면 깔끔합니다.
4. 아래 동작을 **순서대로** 추가합니다(아래 검색창에 이름을 치면 나옵니다).
   1. **클립보드에 복사** — 입력: *단축어 입력*
   2. **URL 인코딩** — "*단축어 입력*을(를) 인코딩"
   3. **텍스트** — 칸에 아래 주소를 붙여넣고, 맨 끝에 변수 **URL 인코딩된 텍스트**를 넣습니다.
      ```
      https://leehagyeol.github.io/Repository/storage/?add=
      ```
   4. **URL 열기** — 입력: *텍스트*
5. 오른쪽 위 **완료**.

> 동작 이름은 iOS 버전에 따라 조금 다를 수 있습니다. 예: "URL 인코딩" → "텍스트 URL 인코딩".

## 쓰기

YouTube 등에서 **공유** → 목록에서 **저장소에 담기** (처음엔 맨 끝 "더 보기"에 있을 수 있음 → 편집에서 위로 올려 두면 편함).

## 열리는 곳에 따라

| 열린 곳 | 화면 | 할 일 |
| --- | --- | --- |
| 홈 화면의 저장소 앱 | 링크가 채워진 추가 시트 | 카테고리·키워드 고르고 저장 |
| Safari 탭 | "홈 화면 앱에서 저장해 주세요" 안내 | 홈 화면의 저장소 앱 → **+** → **붙여넣기** (단축어가 이미 링크를 복사해 둠) |

Safari 탭에서 저장하면 홈 화면 앱과 데이터가 따로라 보이지 않으므로, Safari에서는 저장하지 않고 안내만 합니다.
