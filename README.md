# Repository

## 저장소 (`storage/`)

아이폰 Safari 홈 화면에 추가해 쓰는 개인용 저장소 웹앱입니다. 영상·웹페이지 링크, 사진, 메모를 6개 카테고리(레시피, 육아, 만들기, 쇼핑, 메모, 짤방)로 나눠 모읍니다.

- 앱 주소: https://leehagyeol.github.io/Repository/storage/
- 기획문서: [storage/docs/저장소_기획문서.md](storage/docs/저장소_기획문서.md)
- 단계별 프롬프트: [storage/docs/저장소_Claude_Code_프롬프트.md](storage/docs/저장소_Claude_Code_프롬프트.md)
- 개발 규칙: [storage/CLAUDE.md](storage/CLAUDE.md)

HTML + CSS + JavaScript만 쓰고 빌드 과정은 없습니다. 데이터는 폰 안(IndexedDB)에만 저장됩니다.
